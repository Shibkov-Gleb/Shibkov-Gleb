## Selected projects

### [U.S. Constitution RAG](https://github.com/Shibkov-Gleb/US-Constitution-RAG)

A compact CLI that retrieves relevant Constitution passages before generating an answer. A configurable relevance threshold lets it decline questions outside the source material.

`Python` · `LlamaIndex` · `Chroma` · `OpenAI API`

### [Noseprint](https://github.com/Shibkov-Gleb/Dog-emotion-classifier)

An experimental computer vision app that classifies a dog's visible expression from a photo and returns per-class confidence scores. Combines a fine-tuned ResNet50 model with a web interface and inference API.

`TensorFlow / Keras` · `TensorFlow.js` · `Next.js` · `TypeScript` · `Express` · `Docker Compose`

### [Productivity Predictor](https://github.com/Shibkov-Gleb/productivity_score)

A Telegram bot that estimates daily productivity from habit data. Covers exploratory analysis, model training, consistent preprocessing, and containerized inference.

`Python` · `Machine learning` · `Telegram Bot` · `Docker`
